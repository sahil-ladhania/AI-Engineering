=== ANIMATIONS ===
Use Tailwind + custom CSS only. No framer-motion.

1. Messages fade in from bottom:
   @keyframes slideUp {
     from { opacity: 0; transform: translateY(8px); }
     to   { opacity: 1; transform: translateY(0); }
   }
   Apply: animation: slideUp 0.2s ease-out

2. Blinking cursor on streaming:
   animate-pulse on a cyan 2px wide inline block

3. Sidebar preset cards: 
   transition: all 0.15s ease on hover
   hover: background slightly lighter, left border violet

4. Send button hover: 
   subtle scale(1.05) + glow

5. New Chat button:
   hover: box-shadow: 0 0 12px #7c3aed44
